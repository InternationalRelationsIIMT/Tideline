1. Install Node.js 18 or newer (https://nodejs.org).
2. Open a terminal in this folder and run: npm install
3. Start the server: npm start
4. Open the printed http://<LAN-IP>:3000 URL in your browser and share it on the same Wi-Fi.
5. If prompted by Windows/macOS firewall, allow Node.js to accept incoming local network connections.
6. Optional: set HOST_PIN=1234 to protect leaderboard resets, or run npm run sim to test 10,000 matches.
